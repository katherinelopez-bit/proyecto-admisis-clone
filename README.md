# Sistema Contable

Proyecto de desarrollo de un sistema contable orientado a contadores, que permitirá gestionar información de empresas, clientes, registros contables, reportes, facturación y otras tareas relacionadas con la gestión contable. El objetivo es crear una herramienta moderna, rápida y sencilla de utilizar, que facilite el trabajo diario de los contadores y pueda adaptarse a las necesidades del contexto boliviano
